2. Pagination

Lesson 1  Why Pagination?
=> Suppose db has 5000 products
current code  const products = await productModel.find() => mongoDB return 5000 documents
# slow db query
# more memory usage
# slower server
# large html response
# poor user experience

industry solution => instead of returning 5000 products => return 12 products per page

How does MongoDB know which products belong to Page 2?
=> Using two methods. skip(), limit()



Lesson 2  Understanding skip() & limit()
=> productModel.find().limit(5) => mongoDB returns 5 products
=> productModel.find().skip(5) => mongodb skip 5 products, and start from 6

combine them:
productModel.find().skip(5).limit(5) => skip first 5, and return next 5
productModel.find().skip(10).limit(5) => skip first 10, and return next 5


How do we know how many products to skip? if user request page 7
=> That's where the most important pagination formula comes in.


Lesson 3  Page Calculation - Deriving the Formula

Products per page = 10
If Page 1 shows products 1–10, how many were skipped? 0
If Page 2 shows products 11–20, how many were skipped? 10
Page 1 → Skip 0
Page 2 → Skip 10
Page 3 → Skip 20
Page 4 → Skip 30

pattern:  Skip = (Page Number - 1) × Products Per Page

so this is the universal pagination formula.
skip = (page - 1) * limit

/// req.query always returns strings.

Controller just receive request and coordinates.
Service contains business logic

Calculating pagination is business logic, so it belongs in service.
Controller just bypass page number through service function

const page = Number(req.query.page) || 1;



Lesson 4  Service Implementation

const skip = (page - 1) * limit;
